RMS current in the buck's capacitors

The buck's input capacitor carries a pulsed current of RMS value IoD(1−D)I_o\sqrt{D(1-D)}Io​D(1−D)​, much larger than the output capacitor's, which sees only the inductor's triangular ripple.

A capacitor heats up with the current through it, not with the voltage across it. The loss is Irms2RESRI_{\mathrm{rms}}^2 R_{\mathrm{ESR}}Irms2​RESR​, and the manufacturer gives an RMS current limit for each temperature. So, after choosing the capacitance for the voltage ripple, the current still has to be checked. In the buck, the two capacitors carry very different currents.

The output capacitor

The inductor is in series with the output, and the current reaching the output node is already continuous, with a triangular ripple. The load takes the average, IoI_oIo​, and the output capacitor takes only the triangular part. The output capacitor's RMS current equation, which Sizing L and C uses in step 3, gives ΔiL/12\Delta i_L/\sqrt{12}ΔiL​/12​. It does not depend on the load: with the same ΔiL\Delta i_LΔiL​, the RMS current is the same at 0.5 A or at 2 A.

The input capacitance

The same charge gives the voltage ripple at the input. The capacitor loses (1−D) Io DTs(1 - D)\,I_o\,D T_s(1−D)Io​DTs​ during the pulse, so

with the ESR part, RESR IpeakR_{\mathrm{ESR}}\,I_{\mathrm{peak}}RESR​Ipeak​, with the inductor's peak current, added on top. The sum assumes all the AC current stays in the capacitor; if the source has a low impedance at the switching frequency, part of it goes into the cables, and that is what an input filter prevents.

The lab has no input capacitor

In the buck's netlist, the input is an ideal source: it supplies the whole pulses, with no ripple. On a board, the pulse current flows in the loop formed by the input capacitor and the two switches. That capacitor sits right next to the switches, because the inductance of that loop produces the voltage spike at each commutation (Dead time and switching in the synchronous buck).
