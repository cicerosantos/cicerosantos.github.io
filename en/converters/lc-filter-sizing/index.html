Sizing L and C

How to choose the buck's inductor and capacitor from the ripple specifications, the capacitor's RMS current and the load step.

First, see: Duty ratio and ripple of the buck in CCM

This procedure uses the equations of Duty ratio and ripple of the buck in CCM backwards: it starts from the specifications and arrives at L and C. At the end, we check the lab's buck.

1. Choose the current ripple and compute L

Define the relative ripple r=ΔiL/Io,max⁡r = \Delta i_L / I_{o,\max}r=ΔiL​/Io,max​. Values from 20 % to 40 % are the usual starting point: less calls for a large, slow inductor; more raises the peak, the core losses and the capacitor's RMS current. From the ripple equation,

L=Vo (1−D)r Io,max⁡ fsL = \frac{V_o\,(1 - D)}{r\,I_{o,\max}\,f_s}L=rIo,max​fs​Vo​(1−D)​

Use the highest input voltage: 1−D1 - D1−D grows with VinV_{in}Vin​, and so does the ripple.

Saturation

Check the peak Io,max⁡+ΔiL/2I_{o,\max} + \Delta i_L/2Io,max​+ΔiL​/2 against the inductor's saturation current, not only against its rated current. The inductance of many powdered-iron inductors drops 20 % to 30 % with current, and the ripple rises in the same proportion.

2. Compute C and the maximum ESR from the voltage ripple

With the specified output ripple Δvo\Delta v_oΔvo​, split the budget between the two parts:

C≥ΔiL8 fs Δvo,RESR≤ΔvoΔiLC \ge \frac{\Delta i_L}{8\,f_s\,\Delta v_o}, \qquad R_{\mathrm{ESR}} \le \frac{\Delta v_o}{\Delta i_L}C≥8fs​Δvo​ΔiL​​,RESR​≤ΔiL​Δvo​​

With ceramic capacitors, the ESR is a few milliohms and the capacitive part dominates. With electrolytics, the ESR usually dominates, and the capacitance ends up well above the minimum. Remember that the parts are out of phase: requiring each one below Δvo\Delta v_oΔvo​ already leaves some margin.

Ceramic capacitance under bias

An X5R or X7R ceramic loses a good part of its capacitance with the applied DC voltage. Use the manufacturer's curve at the output voltage, not the rated value.

3. Check the capacitor's RMS current

The buck's output capacitor carries the triangular part of iLi_LiL​:

IC,rms=ΔiL12(1)I_{C,\mathrm{rms}} = \frac{\Delta i_L}{\sqrt{12}}\tag{1}IC,rms​=12​ΔiL​​(1)
≡

Compare it with the capacitor's rated RMS current (or that of the bank), at the working temperature.

4. Check the load step and the resonance

Ripple rarely sets C. In a load step ΔI\Delta IΔI, the capacitor supplies the difference until the loop reacts, and the loop reacts in about 1/(2πfc)1/(2\pi f_c)1/(2πfc​). A first-order estimate of the dip is

ΔV≈ΔI2π fc C\Delta V \approx \frac{\Delta I}{2\pi\,f_c\,C}ΔV≈2πfc​CΔI​

where fcf_cfc​ is the crossover frequency of the loop gain. Finally, compute the resonance f0=1/(2πLC)f_0 = 1/(2\pi\sqrt{LC})f0​=1/(2πLC​) of the plant: it must lie well below fs/2f_s/2fs​/2 and preferably below fcf_cfc​, because the compensator will have to cancel its pole pair.

5. The calculation in Python

from math import pi, sqrt

vin, vo, fs = 24.0, 9.0, 200e3      # input, output, switching
io_max = 2.0                         # maximum load current (A)
r = 0.4                              # desired ripple: 40 % of io_max
dv_max = 0.010 * vo                  # output ripple: 1 % of Vo

D = vo / vin
L = vo * (1 - D) / (r * io_max * fs)          # from the current ripple
di = vo * (1 - D) / (L * fs)
C = di / (8 * fs * dv_max)                    # capacitive part only
esr_max = dv_max / di                         # ESR part only
print(f"D = {D:.3f}, L >= {L*1e6:.1f} uH, C >= {C*1e6:.1f} uF, ESR <= {esr_max*1e3:.0f} mOhm")

# check against the lab's buck
L, C, esr = 22e-6, 47e-6, 5e-3
di = vo * (1 - D) / (L * fs)
print(f"di = {di:.3f} A ({di/io_max:.0%} of {io_max} A), peak {io_max + di/2:.2f} A")
print(f"dv_C = {di/(8*fs*C)*1e3:.1f} mV, dv_ESR = {esr*di*1e3:.1f} mV, "
      f"I_C,rms = {di/sqrt(12):.2f} A, f0 = {1/(2*pi*sqrt(L*C))/1e3:.2f} kHz")

The output:

D = 0.375, L >= 35.2 uH, C >= 5.6 uF, ESR <= 112 mOhm
di = 1.278 A (64% of 2.0 A), peak 2.64 A
dv_C = 17.0 mV, dv_ESR = 6.4 mV, I_C,rms = 0.37 A, f0 = 4.95 kHz

In the converters

The lab's buck uses L = 22 µH and C = 47 µF, with an ESR of 5 mΩ.

  • L: at 2 A, the 1.28 A ripple is 64 % of the current, well above the procedure's 40 %, and at 1 A it exceeds 100 %. The small inductor lets the current change fast, at (Vin−Vo)/L=0.68(V_{in} - V_o)/L = 0.68(Vin​−Vo​)/L=0.68 A/µs, which helps in the load step; the price is a 2.64 A peak and more core loss.
  • C: for 1 % ripple, 5.6 µF would do with the 35 µH inductor (8.9 µF with the 22 µH one). The 47 µF come from the load step: with fcf_cfc​ = 8 kHz and a 1 A step, ΔV≈1/(2π⋅8 kHz⋅47 µF)=0.42\Delta V \approx 1/(2\pi\cdot 8\,\text{kHz}\cdot 47\,\text{µF}) = 0.42ΔV≈1/(2π⋅8kHz⋅47µF)=0.42 V. In the simulation with the 2p2z, the output drops to 8.59 V, a 0.41 V dip.
  • RMS current: 0.37 A, comfortable for any 47 µF ceramic.
  • Resonance: 1/(2πLC)1/(2\pi\sqrt{LC})1/(2πLC​) = 4.95 kHz (4.96 kHz in the model with losses, at 9 Ω), below the 8 kHz crossover and far below fs/2f_s/2fs​/2 = 100 kHz.
