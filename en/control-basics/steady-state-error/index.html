Steady-state error and system type

The number of integrators in the loop gain, the system type, decides for which input the steady-state error goes to zero; the constants KpK_pKp​, KvK_vKv​ and KaK_aKa​ give the error left for a step, a ramp and a parabola.

First, see: Feedback and margins, First-order pole and zero

The loop of Feedback and margins compares the output with the reference. With β=1\beta = 1β=1, as in the lab's converters, the error is E=R−YE = R - YE=R−Y, and

E(s)=R(s)1+T(s)E(s) = \frac{R(s)}{1 + T(s)}E(s)=1+T(s)R(s)​

What is left of it after the transient is the steady-state error, or static error. It comes from the final value theorem:

ess=lim⁡t→∞e(t)=lim⁡s→0s E(s)=lim⁡s→0s R(s)1+T(s)e_{ss} = \lim_{t\to\infty} e(t) = \lim_{s\to 0} s\,E(s) = \lim_{s\to 0} \frac{s\,R(s)}{1 + T(s)}ess​=t→∞lim​e(t)=s→0lim​sE(s)=s→0lim​1+T(s)sR(s)​

The theorem only holds with the closed loop stable. A loop that oscillates has no steady-state error, and the calculation would give a false number.

The integrator: zero steady-state error

A pole at the origin (Pole and zero at the origin: pure integrator and pure differentiator), G(s)=ωi/sG(s) = \omega_i/sG(s)=ωi​/s, has no flat part: the magnitude falls 20 dB per decade at every frequency, crosses 0 dB at fi=ωi/2πf_i = \omega_i/2\pifi​=ωi​/2π, and the phase stays at −90°. For a step, the response is a ramp that never stops: the pure integrator is not BIBO stable (Pole and zero at the origin: pure integrator and pure differentiator).

In the compensator, the integrator's output moves as long as there is an error and stops only when it is zero. That is how the integrator, alone or in the PI, zeroes the static error to a step. In T(s)T(s)T(s), the integrator makes T(0)T(0)T(0) infinite. The price is the phase: −90° at every frequency, added to the plant's.
