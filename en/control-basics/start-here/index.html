Control basics

Start here

What the Read the plant unit of classical control is for, and five questions to find out, in a few minutes, which of its notes you need to read.

The converter and digital-control notes use, without stopping to explain them, poles and zeros, the factored form, the Bode plot and the QQQ factor. This section starts with the first unit of classical control, Read the plant: write a converter's plant in factored form and draw its Bode plot with asymptotes. The examples always come from the lab's converters, and each note ends with the way back to the point that asked for it.

You do not need to read the whole section. Answer the questions below in your head, with paper and a calculator if you like, and only then open the answer. If you get one wrong, the answer says which note to read. If you get them all right, go on to the converter trails. The note Notation: from the reference course to this course translates the notation of courses that use another convention.

5. Which filter?

A circuit has 0 dB at low frequencies and falls 40 dB per decade above 5 kHz. Another rises 20 dB per decade below f0f_0f0​ and falls 20 dB per decade above it. Which filters are these?

Answer

The first is a low-pass, and the second a band-pass. If you got it wrong, read Second-order filters: the catalogue.
